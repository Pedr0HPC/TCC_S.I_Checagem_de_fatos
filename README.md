# Acervo de referências — desinformação, fact-checking e tecnologias de verificação

Repositório de **30 fichamentos-resumo individuais** preparados para apoio a um Trabalho de Conclusão de Curso em Sistemas de Informação, com foco em desinformação, fact-checking, plataformas digitais, eleições e tecnologias de verificação.

Cada documento contém título, autoria, ano, **veículo de publicação ou instituição responsável**, link para a fonte original quando identificado, resumo sintético, abordagem metodológica e possível contribuição à fundamentação do TCC. Os trabalhos foram classificados conforme sua natureza documental, sem tratar dissertações ou monografias como artigos publicados em periódicos.
